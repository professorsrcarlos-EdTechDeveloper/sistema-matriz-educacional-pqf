MATRIZ EDUCACIONAL - Atualização V31

Aplicação: teste da EMEF Pedro de Queiroz Ferreira.

Principais ajustes:
1. Seção "Criar avaliação para aluno ou turma" agora registra:
   - nome completo do aluno;
   - turma;
   - escola;
   - série;
   - prova fixa;
   - código único gerado.

2. O aluno continua digitando somente o código no treinamento.
   Ao reconhecer o código, o sistema identifica automaticamente aluno/turma/escola/prova.

3. Resultado salvo agora registra também a turma.

4. Ferramentas do painel possuem botão Expandir/Recolher.
   A área de criação de avaliação inicia aberta por ser a principal neste uso.

- painel-coordenador.html
